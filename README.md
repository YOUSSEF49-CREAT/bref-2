## 🎯 Objectif du projet

Créer et intégrer plusieurs pages du site **Nexus**, en respectant la charte graphique, l’accessibilité, la performance, et une compatibilité maximale sur tous les appareils.

---

## 📌 Pages développées

| Page         | Description                                                                 |
|--------------|------------------------------------------------------------------------------|
| Properties   | Maquette UI/UX mettant en avant les infos clés de E-sport Nexus             |
| Blog         | Page dynamique avec articles, visuels attractifs et animations légères      |
| Contact      | Formulaire interactif et accessible pour les visiteurs                      |
| Tournament   | Intégration fidèle d’une maquette spécifique pour les tournois              |
| Responsive   | Version mobile/tablette de toutes les pages du site                         |

🧩 Critères de performance

🎨 Conformité aux maquettes : Respect total des couleurs, typographie et disposition.

🌐 Compatibilité multiplateforme : Fonctionne sur les principaux navigateurs.

♿ Accessibilité : Respect des normes WCAG (niveaux A et AA).

✔️ Validation du code : HTML/CSS valides via les validateurs W3C.

🚀 Déploiement : Site hébergé sur une plateforme accessible (Netlify, GitHub Pages…).

📣 Présentation finale : Documentation claire, interface cohérente et fluide.
